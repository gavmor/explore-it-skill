## Key Takeaways

- **Tested = Checked + Explored:** Automated regression checks verify that software behaves as intended under expected conditions; exploratory testing actively uncovers unknown risks. Both are indispensable.
- **Charters over Scripts:** Over-specified test scripts prevent peripheral observation; vague goals never terminate. Charters (`Explore [target] with [resources] to discover [information]`) provide optimal bounded freedom.
- **Subtle Variables Cause Disasters:** Obvious inputs are rarely where critical failures occur; timing races, accumulated state, and environmental mismatches drive severe system failures.
- **Never & Always Invariants:** When expected results cannot be computed in advance, inviolate system invariants establish robust test oracles.
